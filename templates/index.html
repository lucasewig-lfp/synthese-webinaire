Connexion à Claude

La rédaction utilise ton abonnement Claude (Pro ou Max) via Claude Code. Pas de clé API. À faire une seule fois :

1. Ouvre l'app Terminal et colle cette commande pour installer Claude Code :

curl -fsSL https://claude.ai/install.sh | bash

2. Toujours dans le Terminal, connecte-toi à ton compte Claude (une page s'ouvre dans ton navigateur) :

~/.local/bin/claude auth login
